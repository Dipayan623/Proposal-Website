Proposal Website 🌸

A multi-page interactive proposal-themed website built using pure HTML and CSS.
This project creates an emotional, cinematic, and playful experience with animated backgrounds, soft gradients, mystery interactions, and heartfelt storytelling.

✨ Features
Animated starry background
Smooth aesthetic UI
Multi-page navigation experience
Interactive “Mystery Boxes” section
Emotional storytelling pages
Fully responsive layout
Pure HTML + CSS (no frameworks)

📂 Project Structure
Proposal/
│
├── index.html            # Landing / intro page
├── game.html             # Interactive mystery box page
├── whyimadethis.html     # Personal explanation page
├── risk.html             # Risk analysis themed page
├── final.html            # Final emotional page
│
└── .vscode/
    └── settings.json
    
🚀 How to Run
Download or clone the project
Open the Proposal folder
Double-click index.html

Or run using VS Code Live Server.
